# System Design — Course Map

Study notes for **Mastering System Design: From Basics to Cracking Interviews** (Udemy, Rahul Rajat Singh).

These notes are written in simple English. Read them together with the videos. They are original study notes, not a copy of the course slides.

If you have not designed systems before, read [00_HOW_TO_READ.md](00_HOW_TO_READ.md) first. It explains the pictures and the words every later note uses (client, API, database, cache, queue).

## Suggested reading order

```text
01 Fundamentals
        ↓
02 Networking  →  03 Protocols  →  04 Patterns  →  05 Web Concepts
        ↓
06 Scalability  →  07 Storage  →  08 Performance
        ↓
09 Reliability  →  10 Security
        ↓
11 Blueprint  →  12 Case Studies
```

Do not jump to case studies first. First learn the building blocks. Then design big systems.
