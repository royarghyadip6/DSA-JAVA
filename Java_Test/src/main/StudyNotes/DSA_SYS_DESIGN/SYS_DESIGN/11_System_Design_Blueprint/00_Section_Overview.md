# 11 — The System Design Blueprint

This folder matches the course section **The System Design Blueprint**.

The section PDF is one lecture: a **4-step process** from the problem to a design. There is no separate interview-question PDF. The questions at the end of the topic note are the ones this process is built to answer.

Use it as the script for every case study in the next folder.

---

## Why this section exists

The earlier folders are the pieces: networks, data, scale, reliability, security.

This folder is the **order** you use in an interview.

```text
1. What are we building, and what is out of scope?
2. How big is it, and what will break first?
3. Which boxes and APIs connect them?
4. Which tools, and which tradeoff did you accept?
```

Start with the problem. Name a database only in step 4.

**The four steps, in everyday words**

```text
1. What are we building, and what will we leave out?
2. How busy is it, and which part breaks first?
3. Draw the programs and the doors (the APIs)
4. Pick tools, and say what you gave up
```

Use this script out loud on every case study in the next folder. If a word in a case study is new, the earlier section overview defines it.
