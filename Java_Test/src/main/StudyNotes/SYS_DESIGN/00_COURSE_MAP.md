## Suggested reading order

```text
01 Fundamentals
        ↓
02 Networking  →  03 Protocols  →  04 Patterns  →  05 Web Concepts
        ↓
06 Scalability  →  07 Storage  →  08 Performance
        ↓
```

Do not jump to case studies first. First learn the building blocks. Then design big systems.
