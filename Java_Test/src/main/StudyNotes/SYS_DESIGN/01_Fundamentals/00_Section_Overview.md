# 01 — Fundamentals (Introduction)

This folder matches the course **Introduction** section (~6 lectures, about 24 minutes).

It is a short start. The goal is to understand **what** system design is and **why** you are learning it. Deep topics come later.

---

## What this section is

- A simple meaning of system design
- High-Level Design vs Low-Level Design
- Why companies and interviews care about it
- How to study this course without getting lost

---

## What this section is not

Do **not** expect these notes to teach:

- Networking, DNS, TCP, HTTP
- Databases, caching, load balancers
- CAP theorem, sharding, microservices
- Full designs like WhatsApp or YouTube

Those belong to later folders. If a word appears here, it is only a **preview**.

## How each note is written

Every note follows the same pattern:

```text
Simple idea
     ↓
Tiny diagram
     ↓
One real example
     ↓
A few interview lines
```

If you can explain the idea to a friend in 2 minutes, you understood it.
